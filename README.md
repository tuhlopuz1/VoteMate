# VoteMate

Блокчейн-платформа для анонимных и защищённых голосований.
Проект создан командой “Хакатоновые Монстры” как универсальное решение для проведения честных, прозрачных и удобных голосований — от корпоративных опросов до муниципальных выборов.

## 🚀 О проекте

VoteMate — это сервис для создания и проведения голосований с использованием блокчейна и смарт-контрактов.
Главная цель проекта — обеспечить:

* 🔒 Безопасность голосования
* 👤 Анонимность пользователей
* ✅ Невозможность подделки результатов
* 📊 Удобную аналитику
* 🌍 Масштабируемость под разные сценарии использования

## ✨ Возможности

* Создание публичных и приватных голосований
* Анонимное голосование через блокчейн
* Подтверждение уникальности пользователя через Telegram-бота
* Уведомления о результатах голосований
* Аналитика голосований
* Поддержка корпоративных и государственных кейсов
* Интеграция со смарт-контрактами на Solidity

## ⚙️ Как работает VoteMate

### 1. Регистрация пользователя

Пользователь регистрируется на платформе и подтверждает свою уникальность через Telegram-бота.

### 2. Голосование

Пользователь выбирает вариант ответа, после чего создаётся транзакция в блокчейне, подписанная от имени пользователя.

### 3. Аналитика и уведомления

После завершения голосования:

* пользователи получают уведомления,
* автор голосования получает статистику,
* доступна расширенная аналитика через подписку `PollAnalytics Pro`.

---

## 🔐 Почему блокчейн?

VoteMate использует блокчейн для решения ключевых проблем существующих систем голосования:

* невозможность фальсификации результатов,
* прозрачность подсчёта,
* неизменяемость данных,
* защита анонимности участников.

Благодаря подписанию транзакций пользователями результаты невозможно изменить задним числом.
